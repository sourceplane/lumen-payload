# sdk

Runtime-agnostic TypeScript SDK for the Lumen Payload control plane API

A shared package of the lumen-payload workspace, consumed by the components
below at build time.

## Depended on by

- **cli** — First-class TypeScript CLI for the Lumen Payload control plane API
- **web-console-next** — Next.js 15 + opennextjs/cloudflare delivery of the Lumen Payload web console (per-environment, Workers + Static Assets)
